# Time2Work Admin

Next.js (App Router) dashboard for the Time2Work marketplace.

## Run

```bash
cd admin
cp .env.example .env.local
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Seed admin (from backend seed): `admin@time2work.com` / `Admin@123`.

API base defaults to `http://localhost:4000/api` via `NEXT_PUBLIC_API_URL`.
